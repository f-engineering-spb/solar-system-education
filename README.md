# 🪐 Solar System Education: 3D-планетарий NASA

Интерактивный образовательный 3D-планетарий Солнечной системы на базе **Three.js r128**, созданный на основе реальных астрономических данных NASA (JPL / Horizons / SDO / MESSENGER / Viking / Dawn / Giotto).

---

## 🚀 Быстрый запуск

* **В браузере**: просто откройте файл `index.html` (или полностью автономный `solar-system-standalone.html`).
* **Без интернета**: файл `solar-system-standalone.html` содержит все текстуры и библиотеки внутри себя и работает на 100% автономно на любом компьютере без подключения к сети.

---

## 🎮 Управление в 3D

| Действие | Управление | Описание |
| :--- | :--- | :--- |
| **✋ Сдвиг сцены (лапа)** | **Зажать ЛКМ** и тянуть | Перемещение плоскости экрана (Screen-space Pan) |
| **🎯 Захват планеты** | **Клик ЛКМ** по объекту | Центрирование камеры на планете (размер 30% экрана) |
| **🔍 Зум** | **Колесико мыши** | Плавное приближение к поверхности планеты |
| **🔄 Вращение ракурса** | **Зажать ПКМ** и тянуть | 3D-вращение ракурса вокруг выбранной планеты |
| **⏸ Осевое вращение** | Кнопка в карточке справа | Остановка/запуск суточного вращения для изучения рельефа |

---

## 📂 Структура проекта

* `index.html` — основной исходный код 3D-сцены, шейдеров и интерфейса.
* `solar-system-standalone.html` — портативная версия «всё-в-одном» (все текстуры NASA и скрипты Three.js упакованы в Base64).
* `assets/textures/` — текстуры планет NASA высокого разрешения (2K Blue Marble, полосы Юпитера, кольца Сатурна, кратеры Луны).
* `vendor/` — локальные библиотеки `three.min.js` и `OrbitControls.js`.

## 🌟 Возможности для развития (Идеи для сына)

1. Добавление спутников Юпитера (Ио, Европа, Ганимед, Каллисто) и Сатурна (Титан, Энцелад).
2. Траектории исторических космических аппаратов (Вояджер-1, Вояджер-2, Пионер, Новые Горизонты).
3. Интерактивные викторины и познавательные карточки по астрономии.
4. Режим гравитационного маневра (Slingshot effect).
